# Улучшения системы входа в AURUS Control Panel

## Реализованные улучшения

### 1. CLI-утилита для управления пользователями (`manage_users.py`)

**Команды:**
- `python manage_users.py create_admin <username> [password]` - Создать супер-администратора
- `python manage_users.py list` - Список всех пользователей
- `python manage_users.py unlock <username>` - Разблокировать пользователя
- `python manage_users.py set_level <username> <level>` - Установить уровень доступа
- `python manage_users.py reset_password <username> [password]` - Сбросить пароль

**Пример использования:**
```bash
# Создать супер-админа с паролем
python manage_users.py create_admin admin MySecurePass123!

# Создать супер-админа с интерактивным вводом пароля
python manage_users.py create_admin developer

# Посмотреть список пользователей
python manage_users.py list

# Разблокировать пользователя после 5 неудачных попыток
python manage_users.py unlock john

# Сбросить пароль
python manage_users.py reset_password john NewPass456!
```

### 2. Восстановление пароля через email/токен

**Маршруты:**
- `/forgot_password` - Запрос на восстановление пароля
- `/reset_password/<token>` - Страница сброса пароля по токену

**Функции:**
- Генерация криптографически стойкого токена (secrets.token_urlsafe)
- Время действия токена: 24 часа
- Проверка сложности нового пароля
- Безопасность: не показывает, существует ли пользователь

### 3. Защита от перебора паролей (Brute-force protection)

**Механизм:**
- После 5 неудачных попыток входа аккаунт блокируется на 15 минут
- Счётчик попыток хранится в БД
- При успешном входе счётчик сбрасывается

**Поля в БД:**
- `failed_login_attempts` - счётчик неудачных попыток
- `locked_until` - время разблокировки

### 4. Проверка сложности пароля

**Требования к паролю:**
- Минимум 8 символов
- Хотя бы одна цифра
- Хотя бы один спецсимвол (!@#$%^&*(),.?":{}|<>)

**Где применяется:**
- Регистрация нового пользователя
- Сброс пароля
- CLI-утилита (при создании/сбросе)

### 5. Супер-администратор

**Особенности:**
- Флаг `is_super_admin = 1` в БД
- Уровень доступа автоматически выставляется в 7 (Глава)
- Создаётся через CLI-утилиту
- Информация о статусе сохраняется в сессии

### 6. Обновлённая база данных

**Новые поля в таблице `users`:**
```sql
email TEXT                  -- Email для восстановления
is_super_admin INTEGER      -- Флаг супер-админа
reset_token TEXT            -- Токен восстановления
reset_token_expires TIMESTAMP  -- Срок действия токена
last_login TIMESTAMP        -- Последнее время входа
failed_login_attempts INTEGER  -- Счётчик неудачных попыток
locked_until TIMESTAMP      -- Время разблокировки
```

### 7. Обновлённый интерфейс входа

**login.html:**
- Отдельные формы для входа и регистрации
- Поле email при регистрации
- Ссылка "Забыли пароль?" на странице входа
- Информирование о требованиях к паролю
- Подсчёт оставшихся попыток при ошибке

**forgot_password.html:**
- Форма запроса восстановления
- Ввод логина или email
- Информирование о процессе

**reset_password.html:**
- Форма установки нового пароля
- Подтверждение пароля
- Требования к сложности

## Как использовать

### Создание первого администратора

```bash
cd /workspace
python manage_users.py create_admin admin Admin@2026Secure
```

### Вход как администратор

1. Откройте http://localhost:5000/login
2. Логин: `admin`
3. Пароль: `Admin@2026Secure`

### Восстановление пароля пользователем

1. Нажмите "Забыли пароль?" на странице входа
2. Введите логин или email
3. Получите ссылку для сброса (в реальном проекте - на email)
4. Перейдите по ссылке и установите новый пароль

### Разблокировка пользователя

Если пользователь заблокирован после 5 неудачных попыток:

```bash
python manage_users.py unlock username
```
